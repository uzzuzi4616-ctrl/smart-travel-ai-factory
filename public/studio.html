작성한 글은 먼저 검토한 후 티스토리에 게시하세요.

② 사진·제휴 링크

실제 사진의 HTTPS 이미지 주소를 한 줄에 하나씩 넣으세요. AI 글 생성 전·후 언제든 수정하면 본문에 다시 배치됩니다. 이미지 사용 권한을 확인하세요.

내 PC에서 사진을 선택하면 본문과 미리보기에 바로 반영됩니다. 사진은 브라우저에서 축소해 HTML에 포함합니다. 티스토리 HTML 편집기가 데이터 이미지(base64)를 차단할 수 있으므로, 게시 전 반드시 확인하세요. 안정적인 발행에는 공개 HTTPS 이미지 주소를 권장합니다.

링크와 이미지 URL은 이 브라우저에만 저장됩니다. API 키는 브라우저에 저장하지 않습니다.

③ 사진·제휴 링크 미리보기

사진을 업로드하거나 제휴 링크를 입력하면 여기에서 확인할 수 있습니다.

④ 완성 글 미리보기 · 티스토리 게시

글을 생성한 다음 「본문 편집 시작」을 눌러 글을 직접 수정하고, 원하는 문장을 선택해 글자 크기와 제목 형식을 변경하세요. 수정한 HTML이 복사·다운로드에 반영됩니다. PC 사진은 base64 방식으로 티스토리에서 표시되지 않을 수 있습니다.

AI 글을 생성하면 여기에 완성된 본문이 표시됩니다.

⑤ 티스토리 발행 준비

이 목록은 편의용입니다. 티스토리 계정에서 카테고리를 자동으로 읽어온 것은 아니며, 발행 화면에서 동일한 카테고리를 직접 선택해야 합니다.

글 생성 후 미리보기로 링크를 확인하고 전송 준비를 누르세요.

중요: 티스토리 자동 업로드·자동 발행은 지원되지 않습니다. 「전송 준비」는 HTML 복사와 티스토리 글쓰기 페이지 열기까지만 수행합니다. 실제 발행은 티스토리에서 직접 완료해야 합니다.

👀 오른쪽 게시 미리보기
