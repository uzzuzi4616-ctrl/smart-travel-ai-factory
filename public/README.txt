SMART AI FACTORY - InstaCard Studio (standalone demo)

1. index.html 파일을 Chrome 또는 Edge에서 열어주세요.
2. 주제 입력 후 '카드 문구 초안 만들기' 클릭.
3. 카드별 제목/본문 수정, 테마와 이미지 비율 설정.
4. PNG 또는 ZIP 다운로드.

중요:
- AI 자동 문구 생성은 아직 연결되지 않았습니다. 템플릿 초안 기능입니다.
- 이미지 생성 AI, 결제, 로그인, 서버 데이터베이스 기능은 없습니다.
- ZIP 다운로드는 JSZip CDN을 사용하므로 인터넷 연결이 필요합니다.
- 기존 SMART AI FACTORY 프로젝트를 수정한 파일이 아닌 독립 실행형 스튜디오입니다.
- 기존 프로젝트 통합은 원본 프로젝트 ZIP이 필요합니다.
